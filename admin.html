Gérez votre boutique Rona shop

Base de données non configurée Pour activer ce panneau, suivez ces étapes :
  1. Créez un projet gratuit sur console.firebase.google.com (projet dédié à Rona shop).
  2. Activez Realtime Database, puis Authentication → E-mail/Mot de passe, et créez un utilisateur admin.
  3. Dans Realtime Database → Règles, collez :
    { "rules": { ".read": true, ".write": "auth != null" } }
  4. Copiez la configuration web dans firebase-config.js et mettez FIREBASE_ENABLED = true.
